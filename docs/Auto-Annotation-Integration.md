# 自动预标注能力说明

更新时间：2026-10-08

## 1. 开源方案调研结论

| 项目 | 公开热度（约） | 优势 | 对本平台的处理方式 |
| --- | ---: | --- | --- |
| [Label Studio](https://github.com/HumanSignal/label-studio) | 28k+ Stars | 通用数据标注、ML 后端、任务管理 | 不直接嵌入；可在后续需要多人协作时通过导入/导出适配。 |
| [CVAT](https://github.com/cvat-ai/cvat) | 16k+ Stars | 成熟的检测、分割、跟踪和自动标注工作流 | 不直接嵌入；其“模型建议、人工确认、质量复查”流程可作为平台设计参考。 |
| [X-AnyLabeling](https://github.com/CVHub520/X-AnyLabeling) | 10k+ Stars | 单图交互标注体验好，支持 YOLO、Grounding DINO、SAM 等辅助标注 | 作为当前页面交互参考；不复制其代码，避免 GPL-3.0 许可对平台造成约束。 |

Star 数会持续变化，以上仅用于方案筛选，不能替代许可证、运维成本和现场模型效果评估。

## 2. 选择的集成方式

本平台不新增 CVAT、Label Studio 或 X-AnyLabeling 的独立服务。原因是完整引入会造成：

1. 用户需要在两个系统之间切换，数据集、类别和模型版本容易不一致；
2. 需要额外维护数据库、权限、对象存储和 GPU 推理服务；
3. X-AnyLabeling 的 GPL-3.0 许可不适合直接把其代码合入现有平台。

替代方案是在现有“数据集维护 → 训练图片标注”中实现相同的核心工作流：

```text
已发布 YOLO 模型
      ↓
AI 预标注（仅生成候选）
      ↓
用户检查：保留 / 删除 / 移动 / 缩放 / 改类别
      ↓
点击“保存标注”
      ↓
成为可训练真值
```

这样模型、类别字典、素材和训练任务始终在同一个平台内。

## 3. 已实现能力

### 3.1 支持的自动预标注类型

| 数据集标注方式 | 可选模型 | 候选输出 |
| --- | --- | --- |
| 目标检测 | 已发布 `YOLO_DETECTION` | 可编辑检测框、类别、模型置信度 |
| 目标分割 | 已发布 `YOLO_SEGMENTATION` | 模型返回的轮廓点；无轮廓的对象不会伪造成分割标注 |
| 图片分类 | 已发布 `YOLO_CLASSIFICATION` | Top1 类别建议 |

模型与数据集类型不匹配时，接口会拒绝执行。例如，分类模型不能为目标检测数据集生成框。

### 3.2 人工确认边界

- 预标注接口不会写入数据库，也不会改变样本的 `PENDING` 状态；
- 候选框使用虚线显示，并标识为“AI 候选”；
- 用户可删除、移动、缩放或修改类别；
- 只有点击“保存标注”后，样本才成为 `LABELED` 并参与训练；
- 若模型返回了数据集类别字典外的类别，页面会警告，用户需确认类别名称和编号顺序。

这条边界避免自动标注直接污染训练集。

## 4. 接口

```text
POST /api/v1/datasets/{dataset_id}/items/{item_id}/pre-annotations
```

请求示例：

```json
{
  "vision_model_version_id": 12,
  "confidence": 0.25,
  "iou": 0.45,
  "max_detections": 300
}
```

响应中返回 `annotation` 候选、`candidate_count`、模型信息、类别警告和简化推理信息。调用者应把候选交给人工确认，不应直接当作训练标签保存。

## 5. 操作步骤

1. 在“模型中心 → 训练模型维护”中创建并发布与数据集类型匹配的 YOLO 模型版本，且权重路径可访问；
2. 在“数据集维护”创建图片训练数据集，并维护类别字典；
3. 上传素材后，点击“框选标注 / 编辑标注”；
4. 在“AI 预标注”选择已发布模型和置信度阈值，点击“AI 预标注”；
5. 审核候选框或轮廓，必要时修改、删除和补画；
6. 点击“保存标注”，再进入模型训练。

## 6. 后续扩展建议

1. **批量预标注任务**：把多个待标注样本送入后台队列，完成后仍保持 `PENDING`，由用户批量审核；
2. **类别映射模板**：当基础模型类别与数据集类别名称不同（例如 `wire` 与 `harness`）时，允许管理员保存映射；
3. **分割可视化编辑器**：将现有 JSON 轮廓编辑升级为点选多边形编辑；
4. **外部工具适配**：若未来有专业标注团队，可提供 CVAT / Label Studio 的 YOLO、COCO 导入导出，而不是复制业务数据。
